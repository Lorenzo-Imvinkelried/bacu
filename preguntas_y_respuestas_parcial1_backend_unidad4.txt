PREGUNTA 1 (ID: fb-p1-u4-q01) | Tipo: Selección Única | Puntaje: 1.00 ptos.
Tópico / Unidad: Ciclo TDD

ENUNCIADO:
¿Cuál es la secuencia de pasos que compone el ciclo iterativo básico de Test Driven Development (TDD)?

OPCIONES:
  [a] Escribir un test que falle, hacer que el test pase y refactorizar el código resultante.  <--- [CORRECTA]
  [b] Escribir el código de producción, refactorizar la implementación y crear las pruebas unitarias.
  [c] Ejecutar los tests existentes, refactorizar la arquitectura y escribir el código faltante.
  [d] Crear la base de datos, escribir las pruebas de integración y adaptar la capa del servicio.

RESPUESTA(S) CORRECTA(S):
  -> Opción [a]: Escribir un test que falle, hacer que el test pase y refactorizar el código resultante.

JUSTIFICACIÓN / EXPLICACIÓN DE CÁTEDRA:
El ciclo de TDD se basa en tres etapas consecutivas e iterativas: primero escribir un test que falle ("Write a failing test"), luego implementar el código mínimo para hacerlo pasar ("Make the test pass"), y finalmente refactorizar el código manteniendo las pruebas pasando ("Refactor").
