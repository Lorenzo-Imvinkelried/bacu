¿qué comandos debería ejecutar para agregar el archivo al control de versiones, y compartirlo con el resto de los usuarios del repositorio remoto?
Respuesta: Un git add . para añadir todos los cambios hechos.
Luego un git commit -m “detalle-cambios” para guardar en el repositorio local.
Luego se realiza un git push para compartir los elementos y luego los demás usuarios deberían hacer un git pull para obtener esos cambios.
